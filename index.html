BEHIND THE CABINET

THE PORT

Tic-Tac-Toe, Othello and Pong were written in Java with Swing. Browsers don't run Swing, so each one was rewritten in JavaScript — same rules, same AI, same bounce angles, same off-by-one edge cases fixed the same way. The original .java files are in /java-source if you want to compare.

HOW IT MAPS

  • T3Model → t3-model.js
  • ButtonGUI / PaintGUI / ConsoleUI → three renderers
  • OthelloComputerAndAI → othello-ai.js
  • PongPanel.paintComponent → a canvas draw loop
  • JOptionPane → the game-over modal

THE ODD ONE OUT

Chess never was a Swing program — it was built for the browser from the start, which is why it's the one game with no .java beside it. Rules and move generation come from a vendored copy of chess.js; ai.js runs a shallow minimax and then deliberately throws a quarter of its own analysis away, because a search that always plays its best move is far stronger than 800 Elo. Every file is a plain script hanging off window.App — no imports, no build.
